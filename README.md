## Описание

MVP подготовки к охотминимуму: одна страница `exam.html`. Открывается в браузере, в том числе с iPhone через файл, без сети и сборки. Вопросы и сроки взяты из перечня Минприроды.

На странице четыре раздела. Экзамен: 160 случайных вопросов, 2 часа 40 минут, зачёт с 120 правильных. Вопросы для изучения идут подряд с первого, варианты с буквами. Вопросы для проверки знаний идут вперемешку, ответы вразброс и без букв. После выбора виден правильный вариант. Сроки охоты — справочная таблица без проверки и схема, как эти сроки сложить.

Репозиторий: https://github.com/itsEugenCode/ohotminimum

Страница: https://itseugencode.github.io/ohotminimum/exam.html
